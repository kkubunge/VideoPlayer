# 꺼벙이플레이어 (kkubunge Player)

MX 플레이어 스타일의 직관적인 터치 제스처, 내장 파일·폴더 탐색기, 그리고 AI 실시간 자막·음성 자동 번역 기능을 결합한 안드로이드 동영상 플레이어입니다.

---

## 주요 기능

1. **화면 밝기 조절**: 재생 화면 왼쪽 절반 위/아래 드래그 (`0% ~ 100%`)
2. **볼륨 조절**: 재생 화면 오른쪽 절반 위/아래 드래그 (`0% ~ 100%`)
3. **동영상 삭제**: 화면 터치 시 상단 컨트롤 바의 휴지통 아이콘으로 즉시 삭제 (삭제 후 다음 영상 자동 이동)
4. **길게 터치 배속 조절**: 화면 길게 터치 후 좌/우 드래그 시 `x0.5 ~ x6.0` 까지 `0.5x` 단위 실시간 배속 조절
5. **화면 좌/우 드래그 & 앞/뒤 이동 버튼 (개별 설정)**: 화면 좌/우 드래그는 초 단위(3~300초)로 실시간 영상을 보며 이동하고, 하단 앞/뒤 이동 버튼은 초(1~60초) 또는 프레임(1~120F) 단위로 독립 설정 가능
6. **더블터치 앞/뒤 이동**: 화면 좌/우 더블터치 시 설정된 초(3~30초) 또는 프레임(1~60F) 단위만큼 앞/뒤 이동 (중앙 더블터치는 재생/일시정지)
7. **이전/다음 동영상 이동**: 하단 컨트롤러의 이전/다음 버튼으로 같은 폴더 내 영상 연속 전환
8. **폴더 목록 & 전체 파일 탐색기**: 앱 시작 시 동영상 폴더 목록, 계층형 파일 탐색기, 최근 재생 목록 탭 제공 (이름·날짜·용량·재생시간 모두 오름차순/내림차순 정렬 지원)
9. **폴더/파일 관리**: 파일 및 폴더 복사, 이동(클립보드 붙여넣기), 새 폴더 만들기, 이름 변경, 다중 선택 삭제(동반 자막 `.srt`/`.vtt`/`.ass` 함께 처리)
10. **AI 자동 번역**:
    - 외부 자막(`.srt`, `.vtt`, `.ass`) 및 내장 자막 트랙 실시간 다국어 번역 (이중 자막 지원)
    - Google ML Kit 온디바이스 번역 + 온라인 번역 + Gemini 2.5 Flash 문맥 번역 지원
    - 자막이 없는 영상의 경우 오디오 추출(16kHz WAV) 기반 Gemini AI 실시간 전사 및 번역 지원
    - 번역된 자막을 `.ko.srt` 파일로 저장 가능
11. **기타 플레이어 기본 기능**: 화면 잠금, 화면 비율(맞춤/채우기/확대/16:9/4:3), 화면 회전 전환, 이어보기, A-B 구간 반복, PIP(팝업) 모드, 오디오/자막 트랙 선택, 자막 싱크 조절, 취침 타이머, 외부 앱에서 동영상 열기(`ACTION_VIEW`)
12. **즐겨찾기 & 장면 북마크**: 폴더/동영상 즐겨찾기(`즐겨찾기` 탭 모아보기) 및 동영상 특정 재생 시점 북마크 저장·원클릭 이동 지원
13. **동영상 구간 잘라내기**: 재인코딩 없는 무손실 고속 추출(`MediaExtractor` + `MediaMuxer`)로 원하는 구간을 새 `.mp4` 클립(동반 자막 `.srt` 포함)으로 저장 가능
14. **두 손가락 화면 크기 조절**: 재생 화면에 두 손가락을 터치한 상태로 좌우 벌리기/오므리기 또는 좌우 드래그 시 화면 크기를 `50% ~ 400%` 까지 실시간 조절 가능 (화면 비율 버튼으로 100% 초기화)

## 빌드된 APK 내려받기

**[Releases의 `latest`](https://github.com/kkubunge/VideoPlayer/releases/tag/latest)** 에서 `VideoPlayer-debug.apk`를 바로 내려받아 설치할 수 있습니다.
`master` 브랜치에 푸시할 때마다 GitHub Actions(`.github/workflows/android-build.yml`)가 단위 테스트(`testDebugUnitTest`)와 디버그 APK 빌드(`assembleDebug`)를 자동 수행합니다.
